# Context Switching Simulator — SLA Review 2

A browser-based Round Robin context-switching simulator for the Operating System Self-Learning Assessment.

Run `index.html` directly or with VS Code Live Server.

Inputs: Process ID, arrival time, CPU burst time, time quantum, context-switch overhead.
Outputs: Gantt chart, context-switch count, switching overhead, waiting time, turnaround time, response time and CPU utilization.

No database or external library is required.
